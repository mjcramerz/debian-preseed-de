Provenance and reproducibility
------------------------------
Reviewed sources, 2026-09-14:
https://raw.githubusercontent.com/wayland-mirror/wayland-protocols/1.47/staging/ext-workspace/ext-workspace-v1.xml

The wlr URL is a reviewed moving branch, not an immutable source pin. The
repository pins its independently recorded complete wire-signature table
instead. tools/workspace_broker_protocols.py contains every request/event
opcode, argument type/interface/nullability and request/event since-version
used to emit the checked-in protocol.py. Its signature SHA256 is:
21f9f99b1ada3663b5f683c27eba62dcd43c93240a510be2cd6adb5469841764

This is NOT a claimed hash of either upstream XML file. Upstream prose is not
vendored. Regenerate/check only with the repository development tool; the
installer and installed session never run a protocol scanner or compiler.
PyWayland itself, libwayland, CFFI and their licenses are provided by Debian
packages; this repository does not vendor their implementations.
