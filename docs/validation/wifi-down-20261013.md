## Accepted behavior

Wi-Fi remains administratively down at boot and does not automatically scan or
associate with an endpoint. Its installer-owned static profile remains present:
Ethernet IPv4 +1 in the same subnet, the same gateway and resolver policy, and
the existing IPv6 settings where enabled. Connection requires an explicit user
action. Keeping the profile configured does not require activating the radio or
installing live addresses/routes on the down interface.
